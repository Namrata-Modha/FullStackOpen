<h2> Full Stack Open 2025 – My Learning Journey </h2>

This repository is where I’ll be completing the Full Stack Open course by the University of Helsinki. It’s one of the best hands-on programs for modern web development, and I wanted a place to track my progress as I go through each part.

<h3> Why I’m doing this</h3>

I’ve already been working as a full-stack developer, but I wanted to strengthen a few things:

<ul> 
  <li>building React apps the “right” way</li>
  
  <li>sharpening my Node.js fundamentals</li>
  
  <li>getting more comfortable with testing, DevOps, and deployment pipelines</li>
  
  <li>learning tools like TypeScript, GraphQL, containers, and React Native in a structured way</li>
  
  <li> I’ve used many of these technologies in real projects, but this course lets me rebuild my foundation in a clean, academic, and systematic way.</li>
</ul>

<h3>What this course covers</h3>

The course walks through the whole modern web stack:

<ul> React for building single page applications

  <li>Node.js + Express for backend APIs</li>
  
  <li>Testing for both backend and frontend</li>
  
  <li>State management</li>
  
  <li>Routing, custom hooks, and app structure</li>
  
  <li>GraphQL</li>
  
  <li>TypeScript</li>
  
  <li>CI/CD</li>
  
  <li>Containers</li>
  
  <li>React Native</li>
  
  <li>Databases and data modeling</li>
</ul>  
  Everything is project-based, which keeps the learning practical.


<h3>What I expect to gain</h3>

Here’s what I want out of this:
<ul>
  <li>stronger confidence writing full-stack apps with JavaScript</li>
  
  <li>a cleaner mental model of server architecture and client-server communication</li>
  
  <li>better testing habits</li>
  
  <li>practical experience deploying apps the same way real companies do</li>
  
  <li>a portfolio of mini-projects along the way</li>
  
  <li>official University of Helsinki credits for completing the course</li>
</ul>
I’m treating this like self-paced upskilling that’s actually useful for real work, not just theory.
